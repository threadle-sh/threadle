# Fonts (SIL Open Font License)

Self-hosted woff2 files used by the threadle UI (`theme.css` `--font` / `--mono`).

| Family | Role | License |
|---|---|---|
| [Instrument Sans](https://github.com/Instrument/instrument-sans) | UI / body | OFL 1.1 — `OFL-InstrumentSans.txt` |
| [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | Mono / labels / code | OFL 1.1 — `OFL-JetBrainsMono.txt` |

No CDN or Google Fonts fetches — files ship with the web build via `public/`.
